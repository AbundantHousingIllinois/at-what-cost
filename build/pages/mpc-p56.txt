  {ProximaNova-Regular 15.0 #4e5154}Zoning Board of Appeals (ZBA) analysis
[B 49,449,552,510]
  {ProximaNova-Regular 9.0 #000000}MPC compiled a dataset of ZBA applications heard by the ZBA using publicly available meeting minutes from 140 total meetings, 
  {ProximaNova-Regular 9.0 #000000}from April 2012 to October 2023. Total appearances were deduplicated to unique applications, then further narrowed to “closed” 
  {ProximaNova-Regular 9.0 #000000}applications that had been decided by the ZBA. Application types (e. g. the frequency of hair and nail salons among special use 
  {ProximaNova-Regular 9.0 #000000}applications) were estimated using the text available in the minutes describing the application, using a combination of text-search 
  {ProximaNova-Regular 9.0 #000000}and manual checks.

  {ProximaNova-Regular 15.0 #4e5154}Planned Developments
[B 49,550,556,623]
  {ProximaNova-Regular 9.0 #000000}For the findings in the “Understanding Planned Developments” section, MPC used publicly available zoning data containing high-
  {ProximaNova-Regular 9.0 #000000}level underlying data for all of Chicago’s Planned Developments. The dataset contains both the year a Planned Development 
  {ProximaNova-Regular 9.0 #000000}agreement was created and its size, from which MPC analyzed PD creation trends by size over time. This dataset does not contain 
  {ProximaNova-Regular 9.0 #000000}information about which land uses the Planned Development allows or other details about each Planned Development. MPC is 
  {ProximaNova-Regular 9.0 #000000}currently retrieving key information about land uses, bulk and density, and public amenities from individual Planned Development 
  {ProximaNova-Regular 9.0 #000000}agreements to build a more meaningful dataset.
